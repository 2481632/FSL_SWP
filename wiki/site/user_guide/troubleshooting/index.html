Troubleshooting

Common issues and their solutions for AR Flood Visualization.

Installation Issues

App Won't Install

Symptoms: "App not installed" error message

Possible Causes: - Insufficient storage space - Corrupted APK file - Android version incompatibility

Solutions:

  1. Check Storage Settings → Storage → Check available space Need: 150 MB minimum

  2. Re-download APK

  3. Delete the current APK
  4. Download again from official source

  5. Verify file size matches (should be ~120 MB)

  6. Verify Android Version Settings → About Phone → Android Version Required: 11.0 or higher

"App Not Compatible" Error

Symptoms: Play Store or APK says incompatible

Solutions:

  1. Check ARCore Support
  2. Visit ARCore Devices

  3. Your device must be on this list

  4. Update Android Settings → System → System Update Install any available updates

  5. Try Different Device

  6. Not all devices support ARCore
  7. Consider testing on a compatible device

ARCore Installation Fails

Symptoms: Prompted to install ARCore, but installation fails

Solutions:

  1. Update Play Store
  2. Open Play Store → Menu → Settings

  3. Update Play Store to latest version

  4. Clear Play Store Cache Settings → Apps → Google Play Store → Storage → Clear Cache

  5. Manual ARCore Install

  6. Search "Google Play Services for AR" in Play Store
  7. Install directly

Runtime Issues

App Crashes on Launch

Symptoms: App opens then immediately closes

Solutions:

  1. Clear App Data Settings → Apps → AR Flood Viz → Storage → Clear Data Restart app

  2. Reinstall App

  3. Uninstall completely
  4. Restart device

  5. Reinstall from APK

  6. Check Permissions Settings → Apps → AR Flood Viz → Permissions Ensure Camera and Location are enabled

Camera Not Working

Symptoms: Black screen or "Camera permission denied"

Solutions:

  1. Grant Camera Permission Settings → Apps → AR Flood Viz → Permissions → Camera → Allow

  2. Check Camera in Other Apps

  3. Open default camera app

  4. If camera doesn't work there, it's a device issue

  5. Close Other Camera Apps

  6. Close all apps using the camera

  7. Restart AR Flood Viz

  8. Restart Device

  9. Complete device restart often fixes camera issues

GPS Not Working

Symptoms: "Lat: 0.0, Lon: 0.0" or coordinates not updating

Solutions:

  1. Enable Location Services Settings → Location → On Mode: High accuracy

  2. Grant Location Permission Settings → Apps → AR Flood Viz → Permissions → Location → Allow all the time (or While using app)

  3. Go Outdoors

  4. GPS requires clear view of sky
  5. Move away from tall buildings

  6. Wait 30-60 seconds for GPS lock

  7. Restart GPS

  8. Toggle Airplane mode on/off
  9. Or restart device

"Loading Water Level..." Stuck

Symptoms: Loading message never disappears

Solutions:

  1. Check Internet Connection
  2. Open a web browser
  3. Verify you can load websites

  4. Try switching WiFi/mobile data

  5. Check API Status

  6. Pegelonline API may be down

  7. Try again in 5 minutes

  8. Use Demo Mode

  9. Switch to demo mode in settings

  10. This works without internet

  11. Check Location

  12. App only works near Pegelonline stations (Germany)
  13. If outside coverage area, use demo mode

AR Tracking Lost

Symptoms: "Tracking lost" message or water plane disappears

Solutions:

  1. Point at Textured Ground
  2. AR needs visual features to track
  3. Avoid blank walls or uniform surfaces

  4. Point at ground with texture/patterns

  5. Improve Lighting

  6. Use in well-lit areas
  7. Avoid very dark or very bright conditions

  8. Daylight works best

  9. Move Slowly

  10. Rapid movements confuse AR
  11. Slow, steady movements work best

Water Plane Not Visible

Symptoms: Can't see the Water plane

Possible Causes:

  1. You're Far from Water Level
  2. If flood level is below you, plane won't be visible

  3. Check "Fluthöhe" value

  4. Water Level Below Ground

  5. In demo mode with low values

  6. Try increasing simulated water level

  7. Rendering Issue

  8. Restart app
  9. Clear cache

Solutions:

  1. Check Flood Height Display If "Fluthöhe: -45.0 m" → Water is 45m below you (not visible)

  2. Adjust Floor Level

  3. Lower your floor setting

  4. Try "Floor: B3" (basement) to raise water plane

  5. Use Demo Mode

  6. Set high water level
  7. Verify plane is visible

Data Issues

Incorrect Water Levels

Symptoms: Water level seems wrong for your area

Possible Causes: - Data from distant gauge station - Elevation data inaccuracy - GPS positioning error

Solutions:

  1. Check Distance to Station
  2. Pegelonline stations are spaced far apart

  3. Data may be from 10-50km away

  4. Verify GPS Accuracy

  5. Wait for GPS to stabilize (30-60 seconds)

  6. Check GPS coordinates in debug panel

  7. Compare with Official Data

  8. Visit hochwasserzentralen.de
  9. Compare with nearest station

Elevation Data Wrong

Symptoms: "Elev: X m" seems incorrect

Known Issues: - Elevation API accuracy: ±5-10 meters - DEM (Digital Elevation Model) resolution varies

Solutions:

  1. Accept Margin of Error
  2. ±10m is normal for elevation data

  3. App is for visualization, not precision measurements

  4. Verify with Other Sources

  5. Google Earth

  6. Topographic maps

  7. Report Persistent Issues

  8. If consistently wrong (>20m error)
  9. Report to development team

No Internet Connection

Symptoms: Cannot fetch live data

Solutions:

  1. Check Network Settings → Network → Verify connection Test with web browser

  2. Switch Networks

  3. Try WiFi instead of mobile data (or vice versa)

  4. Move to area with better signal

  5. Use Demo Mode

  6. Demo mode works offline
  7. Toggle in settings menu

Performance Issues

App is Laggy

Symptoms: Slow, choppy AR visualization

Solutions:

  1. Close Background Apps Recent Apps → Close all Keep only AR Flood App open

  2. Reduce Graphics

  3. Lower screen brightness

  4. Close resource-heavy apps

  5. Restart Device

  6. Frees up RAM
  7. Clears system cache

Battery Draining Fast

Symptoms: Battery drops rapidly during use

Expected Behavior: - AR apps use 20-30% battery per hour - This is normal for AR technology

Mitigation:

  1. Use Power Saving
  2. Enable battery saver mode

  3. Reduce screen brightness

  4. Limit Session Length

  5. Use app in 10-15 minute sessions

  6. Take breaks

  7. Charge Device

  8. Keep device charged above 50%
  9. Use portable charger if needed

Error Messages

"Camera Permission Denied"

Solution:

Settings → Apps → AR Flood Viz → Permissions
→ Camera → Allow
Restart app

"Location Permission Denied"

Solution:

Settings → Apps → AR Flood Viz → Permissions
→ Location → Allow (While using app)
Restart app

"ARCore Not Installed"

Solution: 1. Tap "Install" when prompted 2. Install "Google Play Services for AR" 3. Return to app

"No Internet Connection"

Solution: 1. Check WiFi/mobile data is on 2. Test internet in browser 3. Restart router/device 4. Use demo mode as fallback

"Invalid API Data"

Solution: 1. API may be temporarily down 2. Wait 5 minutes and try again 3. Use demo mode temporarily 4. Report if persists >1 hour

"GPS Signal Lost"

Solution: 1. Move outdoors 2. Wait for GPS to reacquire (30-60s) 3. Check location services enabled 4. Restart device

Still Having Issues?

If none of these solutions work:

  1. Check System Requirements
  2. Review Compatibility Guide

  3. Ensure device meets all requirements

  4. Report a Bug

  5. Document the issue
  6. Include device model and Android version
  7. Note steps to reproduce
  8. Submit to GitHub issues
